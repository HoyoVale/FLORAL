# System status

Use read-only commands only. Report:

- macOS version and architecture
- uptime and load
- disk free space
- memory pressure summary
- Tailscale connectivity
- gateway process status
- Codex and Peekaboo versions

Do not install software, change settings, restart services, or expose secrets.
